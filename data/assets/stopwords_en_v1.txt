# tfidf-stability English stopword list, version 1
#
# Frozen and versioned deliberately. The stopword set determines the vocabulary
# and therefore every document frequency, every idf value and every score in this
# repository, so it must not be a moving target supplied by a library whose
# contents change between releases.
#
# scikit-learn's built-in English list is deliberately NOT used: its own
# documentation warns that it is known-problematic. This list is a conservative
# set of English function words -- determiners, pronouns, prepositions,
# conjunctions, auxiliary and modal verbs -- and contains no content words.
#
# Format: one lowercase token per line, sorted in ascending UTF-8 byte order.
# Lines beginning with '#' and blank lines are ignored. The file's SHA-256 is
# recorded in data/assets/MANIFEST.sha256 and verified at load.
