# Data

**Nothing in `data/raw/` may be committed.** It is gitignored because the
dataset licence requires it.

## Layout

| Path | Tracked? | What it is |
| --- | --- | --- |
| `data/raw/` | **no** | Downloaded archives. Fetched on demand, never redistributed. |
| `data/interim/` | **no** | Parsed corpora (`*.jsonl`) written by `scripts/build_corpus.py`. |
| `data/processed/` | **no** | Fitted models (`*.tfsx`) and experiment outputs. |
| `data/assets/` | yes | Small committed fixtures that carry no third-party licence. |

## The datasets, and why they are treated differently

### `synthetic_small`: redistributable, regenerated on demand

Generated by `tfidf_stability.datasets.synthetic` from a seed and a spec. It is
not stored in the repository: the spec is 20 lines, and regenerating is faster
than reading a file.

CI uses this corpus. Every property the study needs is controlled here: corpus
size, vocabulary size, the exact-duplicate count and the twin pairs. A real
dataset controls none of them.

```bash
python -c "from tfidf_stability.datasets.loaders import load_dataset; \
           print(load_dataset('synthetic_small').n_documents)"
```

One caveat, recorded as `docs/spec_addenda.md#g22`: the twin mechanism produces
score separations in the **1e−3 to 1e−1** range and cannot go finer. Because
§2.2 normalises `tf = count / L`, a single-token edit is a `1/L` *relative*
perturbation, so a separation of 1e−9 would need a billion-token document. Fine
near-ties are located rather than constructed; see `find_near_ties`.

### `movielens_small`: not redistributable, fetched on demand

MovieLens `ml-latest-small`: 610 users, 9742 films, 100,836 ratings.

> The MovieLens usage licence permits research use and **prohibits
> redistribution**. This repository therefore contains the *parser* and a pinned
> SHA-256, and never the data.

```bash
python scripts/fetch_data.py                       # download + verify + pin check
python scripts/build_corpus.py movielens_small \
    --archive data/raw/ml-latest-small.zip \
    -o data/interim/movielens.jsonl
```

**Why the digest is pinned.** GroupLens updates `ml-latest-small` *in place*, at
a stable URL. Without a pin, the corpus underneath a published number can change
without any signal. `movielens.load` raises `DataIntegrityError` on a mismatch
rather than warning, because batch scripts commonly filter warnings out.

The pin cannot establish authenticity, since upstream publishes no digest of its
own. It establishes **stability**, which is the property the reproducibility
claim needs.

Citation:

> F. Maxwell Harper and Joseph A. Konstan. 2015. The MovieLens Datasets: History
> and Context. *ACM Transactions on Interactive Intelligent Systems* 5, 4:
> 19:1-19:19. <https://doi.org/10.1145/2827872>

### `beir_scifact` and `beir_nfcorpus`: not redistributed, fetched on demand

The test splits of two BEIR benchmarks, each with its own queries and graded
relevance judgements (qrels):

| Name | Documents | Judged queries | Judgements | Grades | Licence |
| --- | --- | --- | --- | --- | --- |
| `beir_scifact` | 5183 | 300 | 339 | 1 | CC BY-NC 2.0 |
| `beir_nfcorpus` | 3633 | 323 | 12334 | 1, 2 | academic use only |

```bash
python scripts/fetch_data.py --dataset beir_scifact
python scripts/fetch_data.py --dataset beir_nfcorpus
```

Each archive is checked against `datasets.beir.PINNED_SHA256` on every load.
A query the split does not judge is dropped. A judgement naming an unknown query
or document is an error, not a skipped row.

> Scientific Claims. *EMNLP 2020*, 7534-7550.

> Vera Boteva, Demian Gholipour, Artem Sokolov and Stefan Riezler. 2016. A
> Full-Text Learning to Rank Dataset for Medical Information Retrieval.
> *ECIR 2016*.

> Nandan Thakur, Nils Reimers, Andreas Rücklé, Abhishek Srivastava and Iryna

## How the fields map onto the model

| Model field | Synthetic | MovieLens | BEIR |
| --- | --- | --- | --- |
| `text` | Zipf-sampled tokens | title + genres + user tags | title + body |
| `popularity` | sampled integer | number of ratings | absent |
| `rating_sum2`, `rating_count` | sampled exact pair | `2 × Σ rating`, count | absent |
| `engagement` | sampled integer | number of tags | absent |

A BEIR document carries no attribute, so every operator falls through to the
identifier on a score tie.

Ratings are stored as the **exact integer pair** `(2 × Σ rating, count)` and
never as a float mean (`docs/spec_addenda.md#g8`). MovieLens ratings are
quantised to halves, so `2 × rating` is always an integer and the representation
is exact on real data as well as on constructed fixtures. Comparison is by
cross-multiplication, so two distinct means can never collide onto one double.

**18 of the 9742 films** appear in no row of `ratings.csv`. Their mean is
undefined, so they carry `has_value = False` and sort last, which exercises G8's
missing-value path against real data rather than a constructed fixture. The
count comes from the pinned archive (`696d65a3…`), not from upstream
documentation.

## Reproducing a published number

Every run manifest carries a `provenance` block naming the dataset, and for
MovieLens the archive digest. A result can therefore be traced to its corpus
after the fact, and `"redistributable": false` marks the ones that cannot be
reproduced from this repository alone.
