# Contributing

This repository is a single-author research and reference artefact: a
self-contained exposition of TF-IDF-based similarity systems and their
numerical stability. It is not open to external contributions.

## Contribution Policy

- Pull requests are not accepted and are not reviewed.
- Feature requests, enhancements and design discussions are not accepted.
- The repository is not maintained as a collaborative project.

These restrictions keep the repository a fixed analytical reference rather
than an evolving software system.

## Errors and Clarifications

Reports of factual errors, mathematical mistakes or unclear exposition are
read on a best-effort basis, without guarantee of response or incorporation.
Reports should concern correctness rather than extensions or alternative
implementations.

## Permitted Use

You are welcome to:

- fork the repository for personal use or independent experimentation;
- adapt the code or text for your own projects, subject to the licence;
- cite or reference this work in academic or technical contexts.

All such use must comply with the licence and its attribution requirements.

## Rationale

Restricting contributions preserves conceptual consistency, reproducibility
of results and alignment with the mathematical scope of the work.
Responsibility for the contents rests solely with the author.
